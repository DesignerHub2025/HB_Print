# HB PRINT — Signature Website

موقع تعريفي تفاعلي لمطبعة HB Print — الشراقة، الجزائر، مصمم باستخدام HTML وCSS وJavaScript دون إطار عمل ثقيل.

## المحتويات

- `index.html` الصفحة الرئيسية، مع بيانات SEO وروابط التواصل.
- `styles.css` تنسيق متجاوب مع مختلف الشاشات، باللغتين العربية والفرنسية.
- `app.js` تبديل اللغات، القائمة، فلترة النماذج، وإنشاء رسالة عرض السعر على واتساب.
- `assets/hb-print-logo.webp` الشعار المرسل بعد تحسين حجمه للاستخدام في الموقع.
- `assets/icon-192.png` و `assets/icon-512.png` أيقونات الموقع.
- `assets/whatsapp-qr.png` رمز QR لرقم واتساب.

## المعاينة دون استضافة

افتح `index.html` باستخدام متصفح حديث. لا يلزم خادم أو تثبيت برامج إضافية، لكن تحميل خطوط Google يحتاج اتصال إنترنت؛ يعمل الموقع بخطوط احتياطية عند انقطاع الاتصال.

## النشر على GitHub Pages

1. أنشئ Repository جديدًا أو افتح مستودع HB Print الخاص بك.
2. ارفع الملفات `index.html` و `styles.css` و `app.js`، مع مجلد `assets` كاملًا إلى **جذر** المستودع، لا داخل مجلد فرعي.
3. افتح **Settings > Pages** ثم **Deploy from a branch** واختر `main` و `/ (root)` واضغط **Save**.
4. افتح عنوان GitHub Pages الذي يعرضه GitHub بعد اكتمال النشر.
5. عند التعديل لاحقًا، قد تحتاج إلى تحديث الصفحة إجباريًا `Ctrl + F5`.
